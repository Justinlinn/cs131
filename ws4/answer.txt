ftext()
The f text function searches for the text inside the files starting from current
folder and its subfolders. It is like a shortcut for using a recursive grep
search.If a user searches ftext error, the word error becomes the first argument
for the function and it then runs the grep using "$1" as the search pattern
and "." as the searching location, which means that it searches the current
folder and everything under it It uses grep, with -i for case sensitive searches,
so that the word error can also match ERROR, ErroR or etc. -I is to ignore
binary files, which are not readable text files. -H will print the file names
-r will recursively find through subfolders, -n to print the line numbers. 
The --color=always will show the matching text in color. The grep result will
be sent into less, which will let the user to scroll though the search results
while -r maintains the color formatting from the grep.

cpg()
Copy and go function. It copies a file or a directory to a destination.If that
destination is a directory, it changes the path automatically to the that directory
once the copy succeeds. The first argument is $1, which is the source being
copied, the $2 is the destination. The if statement checks whether the $2 destination
is a directory with -d. If it is true, it will copy$1 into $2, and cd $2 will only happen if cp $1 $2 works sucessfully.
If $2 is not a directory, then it will just copy normally and won't change the directories.
